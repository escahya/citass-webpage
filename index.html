Citation Assistant

Citation Assistant is a Google Docs add-on that helps users discover relevant citation recommendations directly within Google Docs.

How It Works

  1. Select text in a Google Docs document.
  2. Open Citation Assistant.
  3. Request citation recommendations.
  4. Review the recommended citations returned by the application.

Features

  • Generate citation recommendations from selected document text.
  • Works directly inside Google Docs.
  • Simple sidebar interface.
  • Quick insertion of citation information into documents.
