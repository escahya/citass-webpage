Citation Assistant

Citation Assistant is a Google Docs add-on that helps users discover relevant citation recommendations directly inside Google Docs.

Features

• Select text in a Google Docs document.
• Receive citation recommendations based on the selected content.
• View recommendations directly in the Google Docs sidebar.
• Quickly insert citation information into your document.

Privacy Policy

Citation Assistant only processes the text selected by the user for the purpose of generating citation recommendations.

The application does not sell user data and does not share user content with third parties except as required to provide the service.
