Privacy Policy

Last updated: June 2026

Overview

Citation Assistant is a Google Docs add-on that provides citation recommendations based on text selected by users within Google Docs. The application helps users find relevant citation suggestions while writing documents.

Google User Data Accessed

Citation Assistant accesses the following Google user data:

  • Google Docs selected text: The application accesses only the text that a user explicitly selects within the currently open Google Docs document. The application does not access the entire document unless the user selects the entire document content.
  • User email address: The application accesses the user's Google account email address through the Google userinfo.email permission. This email address is used only to associate feedback submissions with a user and provide support when requested.

Citation Assistant does not access Gmail messages, Google Drive files outside the current document, Google Contacts, Calendar data, or any other Google user data.

How We Use Google User Data

Selected document text is transmitted to the Citation Assistant backend service solely for the purpose of generating citation recommendations requested by the user.

The selected text is analyzed and matched against citation data to provide relevant citation suggestions inside Google Docs.

The user's email address is used only for feedback-related purposes, including:

  • Associating feedback submissions with the user who submitted them.
  • Allowing the developer to respond to user inquiries or reported issues.
  • Helping investigate technical problems reported by users.

The user's email address is not used for advertising, marketing, profiling, or any purpose unrelated to providing and supporting Citation Assistant.

Data Sharing

Selected text and user email information may be transmitted to the Citation Assistant backend service hosted by the developer to provide citation recommendations and process feedback requests.

Google user data is not sold to third parties.

Google user data is not shared with third parties except when necessary to provide the Citation Assistant service requested by the user.

The backend service processes data only for the purposes described in this Privacy Policy.

Data Storage and Protection

Communication between the Google Docs add-on and the Citation Assistant backend service is performed over HTTPS.

Reasonable technical and administrative safeguards are implemented to protect user data from unauthorized access, disclosure, alteration, or misuse.

Selected document text is processed only for generating citation recommendations and is not intended to be permanently stored.

Feedback records may include the user's email address and feedback content for support and improvement purposes.

Data Retention and Deletion

Citation Assistant does not intentionally retain selected document text after citation recommendations have been generated, except where temporary processing retention is required for system operation.

Feedback information, including associated email addresses, may be retained for support and troubleshooting purposes.
