Privacy Policy

Last updated: June 2026

Overview

Citation Assistant is a Google Docs add-on that provides citation recommendations based on text selected by users within Google Docs.

Google User Data Accessed

Citation Assistant accesses only the text that a user explicitly selects within the currently open Google Docs document. The application does not access the entire document unless the user selects the entire document content.

Citation Assistant does not access Gmail data, Google Drive files outside the current document, Google Contacts, Calendar data, or any other Google user data.

How We Use Google User Data

Selected text is transmitted to the Citation Assistant backend service solely for the purpose of generating citation recommendations requested by the user.

The selected text is analyzed and matched against citation data to provide relevant citation suggestions within the Google Docs sidebar.

Data Sharing

Selected text is transmitted to the Citation Assistant backend service hosted by the developer in order to generate citation recommendations.

Google user data is not sold to third parties and is not used for advertising purposes.

Google user data is not shared with third parties except as necessary to provide the citation recommendation service requested by the user.

Data Storage and Protection

Communication between the Google Docs add-on and the backend service is performed over HTTPS.

Reasonable administrative and technical safeguards are implemented to protect user data from unauthorized access, disclosure, or misuse.

Data Retention and Deletion

Citation Assistant does not intentionally retain selected document text after processing is completed unless temporary retention is required for operational purposes.

Users may request deletion of any stored data by contacting the developer at escahya@gmail.com.
